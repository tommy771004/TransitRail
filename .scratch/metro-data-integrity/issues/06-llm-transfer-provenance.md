# 06 — LLM 產生的轉乘資料不得混入真實資料

**What to build:** 目前 curated 快照的轉乘站與各段分鐘數，在靜態拓撲解不出來時會由 LLM 補齊。它的驗證只要求「換乘站出現在該網路的站名清單內」與「各段分鐘數加總落在總時長 ±40% 內」——一個地理上完全錯誤的換乘站可以通過這兩關。

稽核抽驗發現目前寫入的兩個值（Chatuchak Park、Tanah Merah）**恰好都正確**，但那是運氣，不是機制保證。

完成後：LLM 的輸出要嘛不進入已提交資料，要嘛帶有來源標記，使真實性判定器永遠不會把它歸類為實測資料。

**Blocked by:** 04

**Status:** resolved

**驗證（2026-08-02）：** llm-advisory 來源被 normalizedProvenance 判為非真實，不會分類為 scraped/realtime。

- [x] 真實性判定器不會將帶此標記的資料分類為 `scraped` 或 `realtime`
