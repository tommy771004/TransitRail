# 08 — 只有真的知道未來班次的網路才提供未來日期

**What to build:** 倫敦與香港的資料只有抓取當下那一刻是真的，未來六天不是過期的即時快照就是生成的服務型態。使用者現在可以選未來日期並拿到看似完整的結果。

完成後：這兩個網路的日期選擇器只讓使用者選當天，並說明原因。首爾（官方時刻表，依平日／週六／週日假日分型，跨日合法有效）與波士頓（真實排班，服務日正確）維持七天查詢。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 倫敦與香港回報為僅當天
- [ ] 首爾與波士頓回報為七天
- [ ] 日期選擇器依此限制可選範圍，並說明為何受限
- [ ] 即使繞過前端直接以未來日期查詢受限地區，也不會回傳過期的即時資料
