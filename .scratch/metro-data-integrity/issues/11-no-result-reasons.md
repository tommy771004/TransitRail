# 11 — 查無結果時說明原因

**What to build:** 使用者查不到結果時，目前拿到的是一個沒有區別的空狀態。四種完全不同的處境長得一模一樣：

1. 這個路線組合本來就不存在
2. 這個地區只提供當天查詢，你選了未來日期
3. 這個地區目前沒有可驗證的班表資料
4. 路線存在、日期可查，但那天沒有班次

前三種都有明確的下一步（換組合、改日期、去業者官網），第四種才是真的沒辦法。把它們區分開來。

**Status:** ready-for-agent

- [ ] 搜尋在無結果時回傳可區分的原因，涵蓋上述四種
- [ ] 前端依原因顯示對應訊息，「無可驗證資料」的情況附上業者官方查詢管道
- [ ] 「僅供當天查詢」的訊息說明該地區的資料性質，並提供切回當天的方式
- [ ] 訊息在既有的語系中皆有翻譯
- [ ] 測試涵蓋四種原因的判定
