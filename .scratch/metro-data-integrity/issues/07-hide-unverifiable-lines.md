# 07 — 隱藏沒有真實資料的路線與車站

**What to build:** 使用者現在會在車站選單與路線圖上看到大量沒有真實班表支撐的選項——曼谷、新加坡的全部路線（時刻表為固定班距生成）、東京五條只存了兩個站的地鐵線，以及若干完全沒有資料的地區。

完成後：選單與路線圖裡出現的每一條線、每一個車站，背後都有經真實性判定為真實的班表資料。沒有的一律不出現。完全沒有可驗證資料的地區，保留在國家選單中但顯示明確說明與業者官方查詢管道，而不是一個空掉的選單。

套用後的預期結果：

| 網路 | 結果 |
| --- | --- |
| 首爾地鐵、波士頓 MBTA | 保留 |
| 倫敦 TfL、香港港鐵 | 保留（日期限制見 ticket 08） |
| 新加坡 MRT、曼谷 BTS/MRT、東京 Metro／都營 | 隱藏 |
| 中／德／法／比／挪／瑞／馬 地鐵 | 隱藏 |

新加坡與泰國在專案內只有地鐵資料，隱藏後這兩國將完全無結果。這是刻意的取捨。
